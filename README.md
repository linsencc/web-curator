# WebCurator · 网页清选

Bilibili 桌面首页筛选扩展。Chrome 扩展管理页开启开发者模式，加载 extension 目录。更新后重新加载扩展并刷新首页和设置页。

## 配置保存

点击保存设置后，规则、阈值、排序、加载数量、颜色分档和白名单保存在 chrome.storage.local。相同浏览器配置及扩展 ID 下，浏览器重启、重新加载扩展和版本升级均保留。未保存修改不保留；卸载扩展或更换扩展 ID 不会继承原配置；当前不跨设备同步。

## 当前功能

- 动态页面优化默认关闭，可在设置中启用。隐藏动态首页个人资料、发布框、直播列表、右侧横幅和热搜，采用左侧 UP 导航与右侧单列动态。UP 导航独立滚动，分类栏吸顶，保留原生点击与选中状态，不显示搜索框和数量提示；关闭后恢复原布局。
- 扩展重载导致旧页面上下文失效后，停止观察与定时任务并恢复页面。刷新页面后运行新版本。

- 首屏静止时检查可见加载骨架，必要时触发原生加载补齐。最多尝试三轮，失败、超时或用户滚动后停止；不改变用户滚动位置。

- 12 种浅底深字配色参考 Ant Design Colorful Tag（https://ant.design/components/tag/），预览和首页共用 palette.css。分档控件使用统一列标题与水平中心对齐。
- 收起无内容的推荐外层，数据到达后恢复；加载骨架取消显式网格位置以自动补齐空位，普通骨架和原生加载锚点保留。

- 点赞率标签可配置最多 8 档门槛与颜色，命中最高档生效；默认 0% 橙色、5% 绿色、10% 粉色。标签尺寸跟随同卡片原生标签。
- UP 白名单单独列出名称、UID、主页入口并支持移除。
- 修复无链接的小程序广告漏判；隐藏特殊推荐的 floor-skeleton 占位，真正内容到达后重新判断，不隐藏普通视频加载骨架。
- 筛选规则使用紧凑横向布局，各页面固定滚动条预留宽度。

- 广告、直播、赛事、番剧、国创、漫画、综艺、课堂、购物独立过滤开关。
- 三条质量规则可同时启用、排序，各自设置播放量与点赞率阈值：组合规则、只看点赞率、只看播放量。
- 从上往下执行：组合规则要求播放量和点赞率同时低于该规则阈值；单指标规则低于自身阈值则过滤。未命中继续，全部未命中保留，首个命中决定过滤原因。
- 所有普通视频均显示“点赞率 x.xx%”，包括高播放和白名单视频。数据缺失或零播放显示“点赞率 —”；零点赞为 0.00%。
- 不再提供手动屏蔽、UP 屏蔽、标题屏蔽；旧屏蔽字段不参与判断。保留过滤记录、单条恢复和 UP 白名单。
- 扩展启用即运行，没有总开关或预览模式。命中后隐藏整张卡片并压紧网格；单卡片等待最多半秒，具有 CSS 自动恢复兜底。
- 每次向下加载可选原生或 12/24/36/48/60 条。自定义数量通过分轮调用原生滚动加载实现，不改写签名请求参数；错误、空结果或超时停止。数量指原始推荐条数，过滤后显示数量可能更少。

## 架构

| 模块 | 职责 |
| --- | --- |
| settings.js | 默认值、配置校验、规则顺序及旧单模式一次性转换 |
| core.js | 纯函数规则引擎和点赞率计算，无 DOM 或网络依赖 |
| feed-bridge.js | MAIN 世界读取原生 fetch/XHR 推荐响应、首屏数据和原生加载协调 |
| feed-store.js | 校验、去重、限量保存推荐统计，合并卡片数据 |
| cards.js | 识别外层卡片、类型和页面元数据 |
| content.js | 页面控制器：数据变化、卡片生命周期、规则应用和记录提交 |
| rate-tag.js / toolbar.js / layout.js | 幂等标签、工具栏、网格呈现 |
| background.js / messaging.js | 串行持久化及统一消息请求 |
| options.js / records.js | 设置编辑与分页记录界面，各自管理状态 |
| theme.css / content.css | 控制面板样式与首页样式，无旧版本叠加覆盖 |

推荐响应保留不变，以便恢复和原生分页。只提取视频 ID、UP ID、播放量和点赞数；不查询详情或粉丝，不申请 API 跨域权限，不上传记录。内存缓存最多 2000 项、本机记录最多 500 项。记录缩略图仍从 B 站图片服务器加载。

## 验证

```powershell
npm ci
npm test
npx playwright install chromium
npm run test:browser
npm run build
```

浏览器测试需 Playwright，可设置 PLAYWRIGHT_PACKAGE 和 CHROMIUM_EXECUTABLE。使用隔离 Chromium 真实加载 MV3 扩展，模拟首页与推荐响应，覆盖独立阈值、规则排序、保存/重载、恢复、分页、标签、连续两轮 48 条加载、失败停止和切回原生加载；纯函数测试覆盖缺失数据和边界。不会访问用户登录配置。

公开首页已确认推荐样本含 stat.view 和 stat.like；0.12.0 在公开首页连续两轮 48 条加载均获得四次成功的原生 12 条响应。真实账号页面可能因 B 站结构变化而需要更新适配，未知数据保守保留。





## 独立项目结构

- `extension/`：可直接加载的 Manifest V3 扩展，当前实现 Bilibili 适配。
- `tests/`：纯逻辑和隔离浏览器回归。
- `scripts/`：测试入口和发布目录生成。
- `artifacts/`：测试生成截图（不入库）。
- `dist/`：发布文件（不入库）。

项目名为多网站扩展预留空间，当前没有其他网站适配。运行代码暂按职责划分模块，后续新增网站时再提取共享适配接口。浏览器测试使用模拟数据，不代表登录态实站验收。

迁移加载目录可能导致开发版扩展 ID 改变；原配置绑定旧 ID。请保留旧扩展和其配置，确认新目录加载后的配置后再移除旧版本。
